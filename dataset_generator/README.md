# Dataset Generator — Synthetic Forensic Data

## ⚠️ IMPORTANT DISCLAIMER

**ALL data in this dataset is entirely synthetic and fictional.**

- No real people, officers, judges, or examiners
- No real criminal cases or FIR numbers
- No real police stations, courts, or forensic labs
- No real private or sensitive information
- All names are generated by the Faker library
- All forensic reports are fictional templates
- All SHA-256 hashes are computed on synthetic content

**This dataset exists solely for academic research, RAG evaluation, and system testing.**

---

## Usage

```bash
# Install dependencies first
pip install -r requirements_ai.txt

# Generate small dataset (development/validation)
python generate_dataset.py --size small --seed 42

# Generate medium dataset (main evaluation — recommended)
python generate_dataset.py --size medium --seed 42

# Generate large dataset (scalability experiments only)
python generate_dataset.py --size large --seed 42

# Custom seed (different but reproducible dataset)
python generate_dataset.py --size medium --seed 123

# Dry run (validate without DB writes)
python generate_dataset.py --size small --seed 42 --dry-run

# Validate FK integrity after generation
python generate_dataset.py --size small --seed 42 --validate
```

## Reproducibility

All generation is deterministic when using the same `--seed` value:
- Python `random.seed(seed)`
- `Faker.seed_instance(seed)`
- All entity IDs assigned sequentially (no random ordering)
- All relationships built before any randomization
- Results identical across runs on the same machine

## Controlled Scenarios (A–J)

Each dataset size includes multiple instances of each scenario.
See `SCENARIOS.md` for full definitions.

- **Scenario A**: Normal clean evidence flow
- **Scenario B**: SHA-256 hash mismatch → Tamper + Compromised
- **Scenario C**: Custody temporal anomaly (suspicious recording delay)
- **Scenario D**: Derived evidence cascade (parent → children compromised)
- **Scenario E**: Expiring biological evidence alert
- **Scenario F**: Overdue examination (past SLA)
- **Scenario G**: Dead-man switch (30+ day inactivity)
- **Scenario H**: Fully clean case (no anomalies anywhere)
- **Scenario I**: Multiple simultaneous anomalies in one case
- **Scenario J**: Ambiguous/insufficient evidence (no resolution)
