Role-based access control is enforced at the MySQL database level using GRANT/REVOKE statements — not just the application. Each role has specific table-level permissions defined directly in MySQL.
Database Role Permissions (RBAC)
DB RoleSELECTINSERTUPDATEDELETEProcedures

forensic_examiner Evidence, Examinations Examination, Report Examination only None verify_hash
supervisor All Tables All Tables All Tables With approval All procedures

-- To create these roles in MySQL, uncomment in complete_database.sql (Section 8)
CREATE USER 'junior_officer'@'localhost' IDENTIFIED BY 'Junior@2024';
GRANT SELECT ON forensic_coc.Evidence TO 'junior_officer'@'localhost';
GRANT SELECT, INSERT ON forensic_coc.CustodyLog TO 'junior_officer'@'localhost';
